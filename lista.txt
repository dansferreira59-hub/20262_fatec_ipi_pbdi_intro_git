1. Novo diretorio, vinculo com o vs code e terminal interno
  cria o vinculo da pasta no vscode -> file open folder;
2. No terminal cria o repositorio, a pasta .git -> git init
3. Faz as configurações locais -> user.name e user.mail
  git config --local user.name "Daniel Ferreira"
  git config --local user.email dan.fatec2025@gmail.com
4. Configurar o vscode para ser o editor padrão
  git config --global core.editor "code --wait"
5. Dar o nome da branch
  git config --global init.defaultBranch main
6. Verificação -> 
  git config --list  (para paginar seta para cima/baixo ou q para sair)
  ou a versão mais detalhada: git config --list --show-origins
7.  Estados dos arquivos: untracked; tracked(unmodified, modified, staged)
  untracked -> não estou sob controle de versão
  tracked -> estão sobre controle de versão
  unmodified -> versão presente = ultima permanente
  modified -> versão presente está editada em relação a ultima permanente
  staged -> pronto para participar do próximo commit, somente arquivos neste estadosão tornados permanentes com o commit

7.1 git status, mensagem mais curta -> git status -s
mostra como estão os arquivos no diretorio. vermelho untracked, verde staged

8. Introduzindo o arquivo para o controle de versão
  git add calculadora.py

9. Torna a versão permanente e abre a aba para digitar a msg do commit
  git commit

etorio

12. git diff -> mostra o conteudo dos commits
